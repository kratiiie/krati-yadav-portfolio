Forecasting Ericsson Patent Innovation Using Machine Learning

A Python machine learning pipeline to forecast annual patent filings and segment Ericsson’s innovation portfolio for clearer interpretation.

  • Python
  • XGBoost
  • Forecasting

Explore the analysis: Ericsson patent forecasting

Scope. Analysed 30,118 Ericsson patent records from 1976 to 2025 to forecast annual filings.

Approach. Benchmarked Naive Last Value, Linear Regression, Random Forest and XGBoost using MAE, RMSE and MAPE. Applied TF-IDF/SVD-based K-Means clustering for portfolio segmentation.

Finding. XGBoost performed best on the holdout test set, while segmentation improved the interpretability of the patent portfolio.
